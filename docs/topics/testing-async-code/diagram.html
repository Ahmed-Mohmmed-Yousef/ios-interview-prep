1. Invoking Async Test Method

The test runner initiates an async test function marked with async throws. The test runs within Swift Concurrency and can call asynchronous APIs directly.

@Test func fetchUser() async throws {\n let client = UserClient()\n}
Step 1: Invocation: The test runner executes an async throws test function.
Step 2: Awaiting Work: The test pauses at await client.fetchUser() without blocking worker threads.
Step 3: Verification: The async call returns, and #expect verifies the returned model state.
Step 4: Cancellation Testing: The test cancels a Task and verifies that CancellationError is caught properly.
