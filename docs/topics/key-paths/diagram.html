Summary: Key Paths in Swift

  • Step 1: KeyPath Literal — Written with a backslash like \User.name, representing an uninvoked, strongly typed reference.
  • Step 2: Read Access — Evaluated on an instance using subscript syntax: user[keyPath: path].
  • Step 3: Writable Key Paths — WritableKeyPath allows modifying mutable properties through subscripts.
  • Step 4: Functional Usage — Key paths act as functions: users.map(\.name) replaces closures with clean syntax.
