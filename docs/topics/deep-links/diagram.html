https://example.com/products/42
  1. Step 1 (Link Tapped): User taps a standard HTTPS link like https://example.com/products/42.
  2. Step 2 (AASA Verification): iOS checks its cached apple-app-site-association database for example.com.
  3. Step 3 (App Routing): If the app is installed and claims the path, iOS launches the app directly via .onOpenURL.
  4. Step 4 (Safari Fallback): If the app is not installed, iOS loads the website seamlessly in Safari without error alerts.
