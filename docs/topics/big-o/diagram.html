O(1) — Constant Time

Operations stay flat regardless of input size. Reading an array index (arr[0]), checking isEmpty, or looking up a dictionary key on average.

let value = array[0] let isEmpty = text.isEmpty

O(log n) — Logarithmic Time

Halves the candidate set at every step. Binary search on a sorted collection finds an item in 20 operations out of 1,000,000 items.

binarySearch(sortedArray, target: 42)

O(n) — Linear Time

Operations scale directly with input size. Single loop over an array, array.contains, array.insert(at: 0), or string.count.

for item in array { ... } let count = string.count // walks graphemes

O(n^2) — Quadratic Time

Operations scale by the square of input size. Nested loops over the same array or calling contains inside an array loop.

for i in array { for j in array { ... } }
