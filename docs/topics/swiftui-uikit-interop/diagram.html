SwiftUI initializes the Coordinator with makeCoordinator(), then calls makeUIView(context:) exactly once to construct the native UIKit view.

func makeUIView(context: Context) -> UISwitch { let toggle = UISwitch() toggle.addTarget(context.coordinator, action: #selector(Coordinator.changed), for: .valueChanged) return toggle }
  1. Step 1: Creation: makeUIView builds the UIKit instance once and assigns the coordinator as delegate or target.
  2. Step 2: SwiftUI to UIKit: When SwiftUI state changes, updateUIView runs to update properties on the existing UIKit view.
  3. Step 3: User Interaction: User actions in the UIKit control fire target-action or delegate messages to the Coordinator.
  4. Step 4: UIKit to SwiftUI: The Coordinator assigns the new value to the SwiftUI @Binding, completing the feedback loop.
