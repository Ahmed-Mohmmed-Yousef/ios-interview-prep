All steps as text (reduced motion)
  1. Value equality (==): a == b compares the properties inside both objects. Because both have name "Sam", it returns true.
  2. Reference identity (===): a === b checks memory addresses. Because 0x101 != 0x202, it returns false.
  3. Sharing a reference: let c = a copies the reference address without making a new object. Now both a and c point to 0x101.
  4. Identity match (a === c): a === c checks whether both point to the same instance. Because both point to 0x101, it returns true.
