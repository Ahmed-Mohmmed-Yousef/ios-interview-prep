1. Stored Properties

Save constant (let) or variable (var) values directly in instance memory. Constant struct instances freeze all stored properties.

2. Computed Properties

Calculate values dynamically via getter/setter. Allocate no memory in the instance. Must always be declared with var.

3. Lazy Stored Properties

Defer initial value evaluation until first read access. Must always use lazy var. Ideal for expensive calculations or disk I/O.

4. Property Observers

willSet (newValue) runs just before value changes; didSet (oldValue) runs immediately after. Suppressed during initializers.
