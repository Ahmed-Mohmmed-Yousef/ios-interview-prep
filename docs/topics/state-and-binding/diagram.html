1. Parent View Holds @State Source of Truth

ParentView owns the @State variable. SwiftUI stores the value in persistent memory outside the struct.

Source of Truth @State

struct ParentView: View { @State private var isOn: Bool = false var body: some View { ... } }

@State creates a local piece of persistent data. Marking it private ensures clean encapsulation.

Step 1: Local Source of Truth

@State private var isOn = false allocates persistent memory managed by SwiftUI outside the transient view struct.

Step 2: Two-Way Connection

Passing $isOn creates a Binding<Bool> reference to the parent's data without copying memory.

Step 3: Child Mutation

When the child modifies isOn.toggle(), it writes directly to the parent's original persistent storage.

Step 4: View Invalidation & Redraw

SwiftUI detects the mutation, invalidates all dependent views, and redraws the UI with the updated value (true).
