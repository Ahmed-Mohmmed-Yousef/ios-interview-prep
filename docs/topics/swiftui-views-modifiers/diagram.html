Step 1: Base View

Text("Hello") creates a struct conforming to View. Its frame is tightly fitted to the text content.

Step 2: Padding Modifier

.padding(16) wraps the text inside a new layout view, adding 16pt of spacing on all sides.

Step 3: Background Modifier

.background(Color.blue) wraps the padded layout. The entire padded frame is colored blue.

Step 4: Modifier Order Matters

Reversing to .background(Color.blue).padding(16) colors only the inner text, leaving transparent padding outside.
