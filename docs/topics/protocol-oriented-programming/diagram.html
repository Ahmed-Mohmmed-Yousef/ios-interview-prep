Class Hierarchy (OOP) Inheritance

class Vehicle { var speed: Double = 0 } class Boat: Vehicle { /* forced state */ }

Classes force subclasses into a single parent tree with unwanted state.

Protocols (POP) Composition

struct AmphibiousCar: Driveable, Floatable { // adopts both capabilities cleanly! }

Protocols let value types compose multiple independent capabilities.

Step 1 of 4

Summary: Protocol-Oriented Programming

  • Step 1: Class Inheritance — Subclasses inherit all stored properties and methods from a single parent class, causing tight coupling.
  • Step 2: Protocols as Traits — Protocols describe what a type can do without forcing stored state or reference semantics.
  • Step 3: Horizontal Composition — Structs and enums combine multiple protocols using composition (&).
  • Step 4: Protocol Extensions — Extensions provide shared default implementations across all conforming types with dynamic dispatch on requirements.
