Summary: Escaping Closures and Memory Lifecycles

  • Non-escaping (default): Runs synchronously on the call stack before the function returns. No heap allocation, no retain cycles.
  • @escaping: Stored and called after the enclosing function returns. Moves to the heap memory.
  • Retain cycle hazard: If an escaping closure captures self strongly and self owns the closure, neither can ever be deallocated.
  • Capture list [weak self]: Breaks retain cycles by turning self into an optional reference that ARC zeroes automatically upon deallocation.
