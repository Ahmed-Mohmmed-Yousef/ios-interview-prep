Functions mark their signature with throws. When an issue occurs, throw transmits an Error value.

Step 1 of 4: Throwing Errors. Shows how throwing functions signal errors.

1. Throwing Errors

Functions marked with throws emit error values conforming to the Error protocol using the throw statement.

2. do-catch Statement

Captures thrown errors with pattern matching. General catch blocks provide an implicit error constant.

3. Optional Conversion (try?)

Converts errors into nil. Successful operations return an Optional value (Type?).

4. Cleanup (defer)

Guarantees cleanup code executes before leaving scope, running in reverse order (LIFO).
