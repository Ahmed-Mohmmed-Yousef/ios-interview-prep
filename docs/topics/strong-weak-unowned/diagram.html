Person Target Object

apt.tenant = tenant // weak reference assigned

Step 1: apt holds a weak reference to Alex. Strong count is 1 from local variable. Weak reference does not increment strong count.

Step 1: Weak Reference Created

apt.tenant = tenant

Apartment holds a weak reference to Person Alex. Strong count stays 1. Weak reference does not keep the object alive on its own.

Step 2: Strong Variable Released

tenant = nil

The only strong reference to Person is set to nil. Strong reference count drops to 0.

Step 3: Immediate Deallocation

Person.deinit executes

Because strong count reached zero, Person is deallocated immediately. The Apartment stays in memory.

Step 4: Automatic Zeroing

apt.tenant == nil

ARC automatically zeroes the weak reference in Apartment. Reading apt.tenant safely returns nil without dangling pointer crashes.
