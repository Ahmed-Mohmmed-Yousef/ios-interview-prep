Serial Queue One Task at a Time

Concurrent Queue Multiple Threads

serialQueue.async { task1() }

Step 1: Serial queue runs Task 1. Task 2 waits in line. No two tasks ever run together on a serial queue.

Step 1: Serial Task Execution

serialQueue.async { task1() }

Task 1 executes on Thread 1. Task 2 waits in the FIFO queue.

Step 2: Sequential Progression

Task 1 finishes -> Task 2 begins

Task 1 finishes completely before Task 2 begins. Tasks never execute simultaneously.

Step 3: Concurrent Dispatch

concurrentQueue.async { taskA() }; concurrentQueue.async { taskB() }

Both tasks start at the same time on different worker threads (Thread 2 and Thread 3).

Step 4: Independent Completion

Task B (Short) completes before Task A (Long)

Tasks finish according to duration rather than initial submission order.
