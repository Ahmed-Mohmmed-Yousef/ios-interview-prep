1. User Action Triggers Event

The user interacts with the View (for example, tapping a button or pulling to refresh). The View does not process business logic; it immediately forwards the user intent to the ViewModel.

Button("Refresh") { viewModel.loadData() }
Step 1: User Action in View: The user taps a UI element. The View delegates the action directly to the ViewModel.
Step 2: ViewModel Processing: The ViewModel runs presentation logic and invokes domain models or network services.
Step 3: Model Delivers Domain Data: The Model layer returns raw domain entities to the ViewModel without any UI formatting.
Step 4: Observable UI Update: The ViewModel formats domain values into display strings and updates published properties, automatically refreshing the View.
