Step 1: View Appears & Task Starts

VIEW APPEARED
Step 1 of 4
When a view appears on screen, its .task modifier automatically launches an asynchronous task. Work is bound directly to the view's lifetime. 
struct ProfileView: View {
    @State private var user: User?

    var body: some View {
        VStack {
            if let user { Text(user.name) }
            else { ProgressView() }
        }
        .task {
            user = await fetchUser()
        }
    }
}
  1. Step 1: View Appears & Task Starts — The .task modifier triggers automatically upon view appearance.
  2. Step 2: In-Flight Network Fetch — Background request executes while SwiftUI displays ProgressView or placeholder without blocking UI.
  3. Step 3: Auto-Cancellation on Disappear — If the user pops or navigates away, SwiftUI cancels the task cooperatively to save network and battery.
  4. Step 4: Success & View Update — When data arrives, state updates safely on @MainActor, or AsyncImage displays the rendered image.
