1. Base Type ReferenceStatic Type

let item: MediaItem = Movie(name: "Inception") // Compile-time type: MediaItem // Runtime type: Movie

The variable is statically typed as MediaItem, but points to a Movie instance in memory.

Evaluation OutcomeType Inspector

// Inspecting the instance // Choosing operator: is, as?, or as!

Swift inspects runtime type metadata without modifying the underlying instance.

1. Superclass Reference

An instance of a subclass can be referenced by its superclass type (such as MediaItem).

2. Type Checking with is

The is operator tests whether an instance is of a specific type and returns a boolean (true or false).

3. Safe Downcasting with as?

Conditional downcasting (as?) returns an Optional containing the subclass value or nil on failure.

4. Forced Downcasting Hazards with as!

Forced downcasting (as!) triggers a runtime crash if the instance is not of the specified target type.
