1. Protocol Blueprint

A protocol defines required properties and methods without providing physical storage or implementations.

2. Value Type Conformance (Struct)

Structs adopt protocols to gain polymorphic behavior while preserving value semantics and immutability.

3. Reference Type Conformance (Class)

Classes adopt protocols alongside or in place of subclass inheritance hierarchies.

4. Existential Polymorphism ([any Protocol])

Collections can group disparate conforming types into a unified array using [any Protocol].
