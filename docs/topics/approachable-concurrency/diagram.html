Step 1: Default @MainActor Isolation

DEFAULT MAIN ACTOR
Step 1 of 4
In modern Swift approachable concurrency, application target code is isolated to @MainActor by default. Classes, view models, and UI state run on the main thread automatically without repetitive annotations. 
// Modern Swift: app target defaults to @MainActor
final class FeedViewModel {
    var title = "Loading"
    // No explicit @MainActor required!
}
  1. Step 1: Default MainActor Isolation — App target classes and view models run on the main thread automatically.
  2. Step 2: Calling Off-Actor Work — View models initiate an asynchronous hop with await when heavy processing is needed.
  3. Step 3: Background Worker Pool — Functions marked nonisolated or @concurrent execute on background cooperative threads to prevent frame drops.
  4. Step 4: Safe Return to Main — The awaited result hops back to @MainActor safely, updating UI state without data races.
