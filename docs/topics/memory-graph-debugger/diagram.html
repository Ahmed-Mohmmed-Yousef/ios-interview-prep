Step 1: Allocation and Setup

Active Allocation

The app instantiates DetailScreen. The NavigationController holds a strong reference to DetailScreen on the heap.

var screen: DetailScreen? = DetailScreen(name: "Profile") screen?.setup()

Static Summary of Steps:

  1. Step 1: DetailScreen is allocated and held strongly by the navigation stack (RC = 1).
  2. Step 2: DetailScreen creates an onDismiss closure, and the closure strongly captures self (circular strong references).
  3. Step 3: The navigation stack pops DetailScreen. External reference drops to 0, but the cycle keeps RC = 1. Xcode flags the isolated island with a purple badge.
  4. Step 4: Adding [weak self] converts the back-reference into a weak pointer. When popped, both objects deallocate immediately (RC = 0).
