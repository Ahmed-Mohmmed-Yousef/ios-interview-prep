1. Open vs Public

open allows subclassing and overriding outside its module. public allows usage across modules but prevents external subclassing.

2. Package Level

package allows sharing code across modules within the same Swift package while keeping it hidden from external clients.

3. Internal (Default)

internal is the default access level, allowing access anywhere inside the same module or target.

4. Fileprivate and Private

fileprivate restricts access to the source file. private restricts access to the enclosing scope and same-file extensions.
