Step 1: Implicit vs Explicit Animation Scope

ANIMATION SCOPE
Step 1 of 4
SwiftUI offers two animation models: implicit animations scoped to a single view via .animation(_:value:), and explicit animations with withAnimation that animate all views affected by a state change. 
// Scoped implicit animation
CardView()
    .scaleEffect(isHovered ? 1.05 : 1.0)
    .animation(.snappy, value: isHovered)
  1. Step 1: Implicit vs Explicit Scope — .animation(_:value:) scopes to a view, while withAnimation animates all dependent hierarchy changes.
  2. Step 2: Property Interpolation — Views with stable identity animate properties like scale, offset, and color smoothly.
  3. Step 3: Transitions on Identity Changes — Structural views entering or exiting the tree animate using .transition() inside withAnimation.
  4. Step 4: Spring Physics & Interruption Handling — Springs naturally maintain momentum when gestures interrupt an active animation.
