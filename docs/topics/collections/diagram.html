Step 1 of 4: Arrays store ordered elements by integer index and allow duplicates.
All steps as text (reduced motion)
  1. Array: Ordered linear storage with zero-based indices. Elements can duplicate. Direct index access is $O(1)$.
  2. Set: Unordered hash bucket. Duplicates are rejected. Testing membership with contains(_:) is $O(1)$.
  3. Dictionary: Unordered key-value hash map. Keys must be Hashable. Lookup by key returns an optional value.
  4. Out of bounds crash: Accessing an array index that does not exist triggers an immediate fatal runtime crash.
