Developers write localizable strings in Swift using Text("Welcome") or String(localized:).
Text("Welcome")
  1. Step 1 (Code): Developer writes Text("Welcome") or String(localized:) in Swift code.
  2. Step 2 (Extraction): Xcode compiler parses code at build time and automatically inserts the key into Localizable.xcstrings as NEW.
  3. Step 3 (Translation): Translators fill in target languages (Spanish, Arabic, German). The state updates to TRANSLATED.
  4. Step 4 (Runtime): At launch, iOS queries the active device Locale, formats numbers/dates, and automatically mirrors layouts for RTL languages.
