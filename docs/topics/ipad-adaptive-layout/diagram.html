Step 1: Full-Screen iPad (Regular Width)

Step 1 of 4
Regular Size Class
When running full screen on iPad, horizontalSizeClass is regular. NavigationSplitView renders sidebar and detail columns side-by-side.
NavigationSplitView { Sidebar() } detail: { Detail() } // Regular width
  1. Step 1 (Full Screen iPad): horizontalSizeClass is regular. Two-column NavigationSplitView displays sidebar and detail side-by-side.
  2. Step 2 (Split View Drag): User drags multitasking divider from the screen edge to run two apps simultaneously.
  3. Step 3 (Compact Size Transition): Window width narrows below threshold. Trait system updates horizontalSizeClass from regular to compact.
  4. Step 4 (Collapsed Navigation Stack): NavigationSplitView collapses automatically into a single-column NavigationStack with back navigation.
