1. Singleton Pattern

A single shared instance provides global access through static let shared. It initializes lazily and safely in Swift, representing a unique physical or system resource.

final class NetworkManager {\n static let shared = NetworkManager()\n private init() {}\n}
Step 1: Singleton Pattern: Ensures a single shared instance accessed via static let shared and guarded with a private initializer.
Step 2: Singleton Pitfalls: Mutable global state, hidden dependencies across views, and test pollution when tests run out of order.
Step 3: Factory Pattern: Centralizes object instantiation behind a method that returns protocol abstractions, decoupling creation logic.
Step 4: Adapter Pattern: Bridges an incompatible third-party or legacy class to conform cleanly to an internal domain protocol.
