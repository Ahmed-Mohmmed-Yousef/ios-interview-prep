Step 2: Swap Outer Elements

Swap elements at index 0 and 4 using numbers.swapAt(0, 4). Array becomes [50, 20, 30, 40, 10]. Increment left to 1 and decrement right to 3.

Step 3: Swap Inner Elements

Swap elements at index 1 and 3 using numbers.swapAt(1, 3). Array becomes [50, 40, 30, 20, 10]. Increment left to 2 and decrement right to 2.

Step 4: Pointers Meet at Center

left == right == 2. Loop condition left < right evaluates to false. Array is reversed in O(n) time and O(1) space without extra memory.
