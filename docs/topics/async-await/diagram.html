Step 1: Task A runs on Thread 1. It calls fetchUser() and reaches the await keyword.

Step 1: Task Execution

let user = await fetchUser()

Task A executes on Thread 1 until reaching the await suspension point.

Step 2: Suspension & Thread Yield

Task A suspends; Thread 1 yields

Task A is suspended and stored on the heap. Thread 1 is released immediately without blocking.

Step 3: Thread Reuse

Thread 1 executes Task B

Thread 1 picks up Task B immediately. No CPU cores sit idle waiting for network responses.

Step 4: Task Resumption

Task A resumes with user payload

When the network request finishes, Task A resumes execution on an available worker thread.
