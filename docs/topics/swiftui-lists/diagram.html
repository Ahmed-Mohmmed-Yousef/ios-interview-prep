Step 1: Viewport Sizing

Only rows currently fitting inside the visible screen bounds (Rows 0, 1, 2) are instantiated in memory.

Step 2: Scroll Recycling

As the user scrolls, rows leaving the top edge are recycled and removed from active rendering.

Step 3: Just-In-Time Allocation

New rows entering the bottom edge are constructed lazily just before appearing on screen.

Step 4: Contrast with Eager Layouts

A ScrollView with a VStack instantiates all 1,000 views immediately, creating high memory overhead.
