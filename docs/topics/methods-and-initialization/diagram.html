1. Instance & Type Methods

Instance methods run on specific instances; type methods (static func) belong to the type itself.

2. Mutating Methods

Struct and enum methods that modify properties must use the mutating keyword. Cannot be called on let struct constants.

3. Memberwise Initializers

Structs automatically receive an init(properties...) unless overridden. Declare custom inits in extensions to keep both.

4. Failable Initializers

init? returns an Optional instance, returning nil when setup validation fails.
