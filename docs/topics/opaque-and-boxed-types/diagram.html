Opaque Type (some) Static Type

func makeShape() -> some Shape { return Circle(radius: 10) }

Compiler knows the exact concrete type: Circle. Zero runtime overhead.

Boxed Type (any) Existential Box

let shapes: [any Shape] = [ Circle(radius: 5), Square(side: 10) ]

Holds any conforming type at runtime using an existential container box.

Step 1 of 4

Summary: some vs any

  • Step 1: Opaque Type (some) — Represents one fixed concrete type known to the compiler. Callers only see the protocol contract.
  • Step 2: Boxed Type (any) — Wraps conforming values in an existential container with a value buffer, type metadata, and witness table.
  • Step 3: Heterogeneous Storage — Only any can store different conforming types (like Circle and Square) inside a single array.
  • Step 4: Dispatch Trade-off — some uses fast, direct static dispatch with stack storage. any uses dynamic witness table dispatch.
