All steps as text (reduced motion)
  1. Declare constant: let maxScore = 100 creates a permanently locked container storing 100.
  2. Attempt reassignment: maxScore = 120 produces a compile error; the constant resists change.
  3. Declare variable: var currentScore = 0 creates an open container storing 0.
  4. Mutate variable: currentScore = 25 replaces the 0 with 25 smoothly without error.
