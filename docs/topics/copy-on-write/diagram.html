Step 1 of 4

Summary: Copy-on-Write (COW)

  • Step 1: Initial Allocation — Variable 'a' holds a lightweight stack struct pointing to a heap storage buffer (ref count = 1).
  • Step 2: Shallow Copy — Assigning 'var b = a' copies only the pointer. Both variables share Buffer 1 (ref count = 2). No memory copy occurs.
  • Step 3: Uniqueness Check — Before mutating, variable 'b' checks isKnownUniquelyReferenced. It detects that the buffer is shared.
  • Step 4: Buffer Duplication — 'b' allocates Buffer 2, copies the elements, and appends the new value. 'a' remains unchanged with Buffer 1.
