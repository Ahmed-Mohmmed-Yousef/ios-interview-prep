Step 1: The Data Race (Shared Mutable Class)

Data Race Hazard
Step 1 of 4
Two separate threads access the same class instance on the heap at the same time without locks. One writes while the other reads, causing memory corruption or crashes.
// Swift 5 hazard: class GameState { var score = 0 } let state = GameState() Task { state.score += 10 } Task { print(state.score) } // Unsynchronized data race
