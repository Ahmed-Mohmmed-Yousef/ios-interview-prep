Step 1: ViewController holds Service strongly. Service holds ViewController strongly through delegate. A retain cycle is born.

Step 1: Circular Strong References

vc.service.delegate = vc

ViewController holds Service strongly. Service delegate holds ViewController strongly. Both strong reference counts stay above zero.

Step 2: External Pointer Released

vc = nil

The navigation stack dismisses the controller and sets vc to nil. Strong count of ViewController drops to 1, held by Service.

Step 3: The Retain Cycle (Memory Leak)

Both objects trapped in heap

Because each instance holds a strong reference to the other, neither count can reach zero. Memory is leaked permanently.

Step 4: The Solution (weak var delegate)

weak var delegate: ServiceDelegate?

Marking delegate weak breaks the cycle. When vc = nil, ViewController drops to 0, frees Service, and both deallocate cleanly.
