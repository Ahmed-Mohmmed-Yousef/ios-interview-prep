Swift 6 Error
Step 1 of 4
Swift 5 generated a warning that was often ignored. In Swift 6, passing a mutable reference type across a task boundary produces a hard compiler error.
// Swift 6 Error: class UserState { var score = 100 } let state = UserState() Task.detached { print(state.score) // Error: passing non-Sendable 'state' }
