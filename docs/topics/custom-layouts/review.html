The simple idea

SwiftUI provides built-in layout containers like VStack, HStack, and ZStack.

However, some user interfaces require unique layouts. Examples include tag clouds that wrap to new lines, or circular button rings.

In iOS 16 and later, Apple introduced the Layout protocol.

Conforming to Layout allows you to create first-class layout containers.

The protocol requires only two core methods.

First, sizeThatFits reports how much space the container needs for a proposed size.

Second, placeSubviews assigns exact coordinates to each child view within the allocated bounds.

Think of it like this

Think of packing items into a suitcase. First, you measure all your clothes to decide how large a suitcase you need. Then, you place each folded item into its specific spot inside the bag.

Custom layouts also support an optional cache. You can calculate expensive math once during sizing and reuse it during placement.

Child views can pass custom layout values up to your container using LayoutValueKey.

In code

Here is an example calculating total layout height for wrapping items. This simulates the logic inside sizeThatFits.

struct ItemSize {
    let width: Double
    let height: Double
}

struct FlowCalculator {
    let maxWidth: Double

    func calculateSize(items: [ItemSize]) -> (width: Double, height: Double) {
        var currentX = 0.0
        var currentY = 0.0
        var lineHeight = 0.0

        for item in items {
            if currentX + item.width > maxWidth && currentX > 0 {
                currentX = 0
                currentY += lineHeight
                lineHeight = 0
            }
            currentX += item.width + 8.0
            lineHeight = max(lineHeight, item.height)
        }
        return (maxWidth, currentY + lineHeight)
    }
}

let calc = FlowCalculator(maxWidth: 200.0)
let items = [ItemSize(width: 80, height: 30), ItemSize(width: 90, height: 30), ItemSize(width: 70, height: 30)]
let total = calc.calculateSize(items: items)
print("Total Height: \(total.height)")

OutputTotal Height: 60.0

Once sizing is determined, placeSubviews assigns exact coordinates to each child.

struct PlacedPoint {
    let index: Int
    let x: Double
    let y: Double
}

struct EqualSpacingPlacer {
    let spacing: Double

    func place(items: [Double]) -> [PlacedPoint] {
        var currentX = 0.0
        var points: [PlacedPoint] = []
        for (i, width) in items.enumerated() {
            points.append(PlacedPoint(index: i, x: currentX, y: 0.0))
            currentX += width + spacing
        }
        return points
    }
}

let placer = EqualSpacingPlacer(spacing: 10.0)
let points = placer.place(items: [50.0, 50.0, 50.0])
print("Last X: \(points.last?.x ?? 0.0)")

OutputLast X: 120.0

This clean separation gives custom layouts full participation in animations and frame calculations.

How can a child view pass custom metadata, like a layout priority or flex weight, to a parent Layout?

Interview traps

Trap

If your layout performs expensive line-wrapping math, do not compute it twice. Use makeCache(subviews:) to calculate line indices once and reuse them.

Trap

The subviews array contains LayoutSubview proxy values. You measure them using subview.sizeThatFits() and place them using subview.place().

How to answer in the interview

Mid answer

The Layout protocol allows us to build custom container views like flow layouts or circular arrangements. We implement sizeThatFits to report the container total size based on subview measurements. Then, we implement placeSubviews to position each child at an exact point inside the given bounds. When calculations are heavy, we use makeCache to store computed positions and share them between passes.

Senior answer

Before iOS 16, custom multi-child layouts required fragile GeometryReader chains and preference keys that caused layout loops. The Layout protocol integrates directly into SwiftUI layout negotiation. It accepts a ProposedViewSize with optional dimensions, measures subviews without view re-instantiation, and places them via LayoutSubview. For advanced arrangements, I use LayoutValueKey to support child-specific flex weights or alignment traits with full animation support.

Recap

The Layout protocol creates custom container views in modern SwiftUI. Implement sizeThatFits to calculate bounding box dimensions. Implement placeSubviews to position children within allocated bounds. Use makeCache to share expensive measurement math between sizing and placement passes.
