1. Base Class Definition

Swift classes do not require a universal root object. Any class without a superclass is a base class.

2. Subclassing

A subclass inherits stored properties, computed properties, and methods from its superclass.

3. Overriding and Super

Subclasses use the override keyword to customize behavior and can call super to run parent logic.

4. The Final Keyword

Marking classes or methods final prevents future subclassing and enables fast direct static dispatch.
