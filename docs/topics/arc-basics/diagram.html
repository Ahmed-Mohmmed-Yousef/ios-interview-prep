Stack Local Variables

Heap Managed Object

var ref1: Person? = Person(name: "Taylor")

Step 1: Memory is allocated on the heap for Person. ref1 holds a strong reference. Strong reference count is 1.

Step 1: Initialization (Count = 1)

var ref1: Person? = Person(name: "Taylor")

Memory is allocated on the heap. ref1 holds a strong reference. Count is 1.

Step 2: Second Reference (Count = 2)

var ref2: Person? = ref1

ref2 is assigned the same reference. Two active strong references point to the heap object. Count is 2.

Step 3: Release One Reference (Count = 1)

ref1 = nil

ref1 is set to nil. ref2 still holds a strong reference. Object stays alive. Count is 1.

Step 4: Count Reaches Zero (Deallocated)

ref2 = nil

ref2 is set to nil. Strong count drops to 0. Swift calls deinit immediately and reclaims heap memory.
