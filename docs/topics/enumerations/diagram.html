Step 1 of 4: Basic Enum. Shows discrete named cases without stored values.

1. Basic Enumerations

Defines a group of related named cases. Cases do not carry integers by default. Dot syntax (.caseName) provides clear, concise code.

2. Raw Values (Uniform & Fixed)

Every case is prepopulated with a compile-time constant of the same type (Int, String, Character). Integers auto-increment. Initialized with init?(rawValue:), returning an Optional.

3. Associated Values (Dynamic & Per-Instance)

Different cases can store custom data payloads of different types. Values vary for each instance created at runtime. Extracted using pattern matching in switch statements.

4. The Golden Rule

An enum case can have raw values OR associated values, but never both on the same enum.
