Step 1: VoiceOver Focus

Step 1 of 4
Focus Acquired
VoiceOver places a visual accessibility cursor (black outline with blue glow) around the active UI control. It looks up the corresponding node in the accessibility tree.
button.isAccessibilityElement = true
  1. Step 1 (Focus): VoiceOver focuses on the interactive element and accesses its node in the accessibility tree.
  2. Step 2 (Label): VoiceOver speaks the accessibility label ("Play"). Never include the word "button" in the label.
  3. Step 3 (Trait): VoiceOver speaks the element traits ("Button") to inform the user how to interact.
  4. Step 4 (Hint): After a brief pause, VoiceOver speaks the optional accessibility hint ("Starts track playback").
