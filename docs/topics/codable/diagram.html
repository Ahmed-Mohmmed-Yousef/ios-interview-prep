Summary: Codable Architecture in Swift

  • Codable typealias: Combines Encodable (Swift to JSON) and Decodable (JSON to Swift).
  • Automatic Synthesis: When all stored properties conform to Codable, Swift synthesizes keys and initializers automatically.
  • CodingKeys Enum: Maps snake_case JSON keys (e.g. "full_name") to camelCase Swift properties (fullName).
  • Custom Decoding: Implementing init(from decoder:) allows custom fallback values using decodeIfPresent.
