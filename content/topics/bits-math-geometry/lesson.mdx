## The simple idea

Bitwise operations, mathematical properties, and geometric formulas solve problems that look complex at first glance.

<Analogy>
  Think of a light switch board. Each switch is one bit: on (1) or off (0). Flipping a switch twice leaves the light in its original state.
</Analogy>

### Bit Manipulation
Computers store numbers as binary digits (bits). Swift provides bitwise operators:

- **AND (`&`)**: Both bits must be 1.
- **OR (`|`)**: At least one bit must be 1.
- **XOR (`^`)**: Bits must differ. `x ^ x = 0` and `x ^ 0 = x`.
- **Shift (`<<` and `>>`)**: Shifting left multiplies by two. Shifting right divides by two.

The expression `n & (n - 1)` clears the lowest set bit. This provides a fast test for powers of two: `n > 0 && (n & (n - 1)) == 0`.

In Swift, you use bitmasks with the `OptionSet` protocol to combine multiple configuration flags efficiently.

### Math & Number Theory
The Euclidean algorithm computes the greatest common divisor (GCD) in logarithmic time. In Swift, `%` is the remainder operator, not mathematical modulo.

### Geometry
Coordinates in 2D space use $(x, y)$ points. To test if three points are collinear, compare slopes using cross-multiplication:

$$(y_2 - y_1) \cdot (x_3 - x_1) == (y_3 - y_1) \cdot (x_2 - x_1)$$

Cross-multiplication avoids division by zero and floating-point precision inaccuracies. In iOS, CoreGraphics models 2D space with `CGPoint`, `CGSize`, and `CGRect`.

## In code

Here is how to use bitwise operations to find a single number, verify powers of two, and count set bits.

```swift
func singleNumber(_ nums: [Int]) -> Int {
    var result = 0
    for num in nums {
        result ^= num
    }
    return result
}

func isPowerOfTwo(_ n: Int) -> Bool {
    return n > 0 && (n & (n - 1)) == 0
}

func countBits(_ n: Int) -> Int {
    var count = 0
    var value = n
    while value > 0 {
        value &= (value - 1)
        count += 1
    }
    return count
}

print("Single number: \(singleNumber([4, 1, 2, 1, 2]))")
print("Is 16 power of two: \(isPowerOfTwo(16))")
print("Set bits in 11: \(countBits(11))")
```
```output
Single number: 4
Is 16 power of two: true
Set bits in 11: 3
```

Next, here is the Euclidean GCD algorithm and a collinear point test using cross-multiplication.

```swift
func gcd(_ a: Int, _ b: Int) -> Int {
    return b == 0 ? a : gcd(b, a % b)
}

func areCollinear(_ p1: (Int, Int), _ p2: (Int, Int), _ p3: (Int, Int)) -> Bool {
    let dy1 = p2.1 - p1.1
    let dx1 = p2.0 - p1.0
    let dy2 = p3.1 - p1.1
    let dx2 = p3.0 - p1.0
    return dy1 * dx2 == dy2 * dx1
}

print("GCD of 48 and 18: \(gcd(48, 18))")
let pt1 = (0, 0), pt2 = (2, 2), pt3 = (5, 5)
print("Are points collinear: \(areCollinear(pt1, pt2, pt3))")
```
```output
GCD of 48 and 18: 6
Are points collinear: true
```

## Interview traps

<Trap label="Dividing slopes directly with floating point types">
  Vertical lines cause division by zero. Floating-point division introduces precision inaccuracies where equal slopes appear unequal. Always use cross-multiplication `dy1 * dx2 == dy2 * dx1`.
</Trap>

<Trap label="Assuming % is modulo for negative numbers in Swift">
  In Swift, `%` is remainder, not Euclidean modulo. For example, `(-1) % 5` equals `-1`, not `4`. To get a positive modulo, write `(n % m + m) % m`.
</Trap>
