## The simple idea

<Analogy>
Think of operators like tools in a toolbox. Some tools work on one item, like flipping a light switch. Other tools compare or combine two items, like a scale. Identity comparison is like checking passport numbers. Two passports can have the same name, but only matching passport numbers prove they belong to the same person.
</Analogy>

In Swift, an **operator** is a symbol or phrase that checks, changes, or combines values.

Swift groups operators by how many targets they work on:
- **Unary operators** work on one target, such as `-count` or `!isReady`.
- **Binary operators** work on two targets, such as `a + b` or `x == y`.
- **Ternary operators** work on three targets. Swift has only one ternary operator: `condition ? answer1 : answer2`.

In older languages like C, writing `if x = y` assigns a value by mistake instead of checking if two values match. Swift stops this bug completely. The assignment operator `=` and compound assignments like `+=` **do not return a value** (their type is `Void`), so `if x = y` fails to compile.

Swift gives you standard math (`+`, `-`, `*`, `/`, `%`), comparison (`==`, `!=`, `<`, `>`), and logical (`!`, `&&`, `||`) operators. The remainder operator `%` gives the leftover after dividing integers. Unlike some languages, Swift keeps the sign of the first number, so `-9 % 4` is `-1`.

Standard math operators check for **integer overflow** by default. If a math result goes past the limits of an integer type, Swift stops the app with a crash. In C, the number can wrap silently or cause bugs. When you really want wrapping behavior, you use overflow operators such as `&+`, `&-`, and `&*`.

Swift also separates value equality from reference identity. Use `==` to check if two values have the same data. Use `===` to check if two class references point to the same instance in memory.

## In code

<CodeExample title="Remainder, compound assignment, and overflow">

```swift
let remainder = -9 % 4
print("Remainder: \(remainder)")

var a = 10
a += 2
print("Total: \(a)")

let maxByte = Int8.max
let wrapped = maxByte &+ 1
print("Wrapped: \(wrapped)")
```

```output
Remainder: -1
Total: 12
Wrapped: -128
```

</CodeExample>

This example shows three safety and math rules:
- **`-9 % 4`**: Gives `-1` because `%` keeps the sign of the first number.
- **`+=`**: Adds and stores the new value, and returns `Void` just like `=`.
- **`&+`**: Explicitly wraps around when `Int8.max` (`127`) overflows to `-128`. Standard `+` would crash instead.

<CodeExample title="Closed and half-open range operators">

```swift
let closedRange = 1...3
print("Closed contains 3: \(closedRange.contains(3))")

let names = ["Alex", "Dana", "Sam"]
let halfOpenRange = 0..<names.count
print("Half-open contains 3: \(halfOpenRange.contains(3))")

let countdown = (1...3).reversed()
for number in countdown {
    print(number)
}
```

```output
Closed contains 3: true
Half-open contains 3: false
3
2
1
```

</CodeExample>

Swift gives you two main range operators:
- **Closed range operator (`a...b`)**: Runs from `a` up to and including `b`. The lower bound `a` must be less than or equal to `b`.
- **Half-open range operator (`a..<b`)**: Runs from `a` up to, but not including, `b`. This is useful for arrays with `.count`, because array indices start at `0`.

To count down, make a normal range first and call `.reversed()`.

<CodeExample title="Ternary conditional and nil-coalescing">

```swift
let score = 85
let message = score >= 70 ? "Passed" : "Try again"
print("Status: \(message)")

let customName: String? = nil
let defaultName = "Guest"
let activeUser = customName ?? defaultName
print("User: \(activeUser)")
```

```output
Status: Passed
User: Guest
```

</CodeExample>

This example shows two shortcut operators:
- **Ternary conditional operator (`condition ? a : b`)**: Checks a `Bool` condition. It returns `a` when `true`, or `b` when `false`.
- **Nil-coalescing operator (`??`)**: Unwraps an optional when it has a value. When the optional is `nil`, it runs and returns the default value on the right.

The `??` operator uses **short-circuit evaluation**. If the optional already has a value, Swift skips the right side completely, so a function or heavy work on the right never runs.

## Interview traps

<Trap title="Assuming closed ranges can count backwards directly">
Writing `5...1` causes a fatal crash at runtime. In Swift, range bounds must keep `lowerBound <= upperBound`. To count down from 5 to 1, write `(1...5).reversed()`.
</Trap>

<Trap title="Confusing value equality == with reference identity ===">
The `==` operator checks whether two values have equal data. The `===` operator checks whether two references point to the same class instance in memory. Value types like structs and enums do not support `===`.
</Trap>

<Trap title="Expecting assignment to return the assigned value">
In languages like C or JavaScript, `a = b` returns the assigned value. In Swift, `=` and compound assignments like `+=` return `Void`. Writing `if let x = y` is valid optional binding, while `if x = y` fails to compile.
</Trap>

## How to answer in the interview

<InterviewAnswer level="fresh">
Operators in Swift are symbols that check, change, or combine values. Swift includes math, comparison, logical, range, and nil-coalescing operators. A key safety rule is that assignment does not return a value, so you cannot assign by mistake inside an `if` condition. We use `==` for value equality and `===` for reference identity.
</InterviewAnswer>

<InterviewAnswer level="junior">
Swift operators focus on safety and clear intent. Standard math operators stop with a runtime crash on integer overflow instead of wrapping silently like C, unless you use overflow operators like `&+`. Assignment returns `Void`, which stops accidental `if x = y` bugs. Swift offers closed ranges `a...b` and half-open ranges `a..<b`, both requiring `lowerBound <= upperBound`. The `??` operator unwraps optionals using short-circuit evaluation, so the default expression only runs when the left side is `nil`.
</InterviewAnswer>

## Recap

<Recap>
- Swift groups operators into unary, binary, and ternary types.
- Assignment `=` and compound assignments like `+=` return `Void` to stop accidental assignment inside conditions.
- The remainder operator `%` keeps the sign of the first number, so `-9 % 4` is `-1`.
- Standard math operators trap on overflow by default; `&+`, `&-`, and `&*` opt into wrapping.
- Closed ranges `a...b` include both ends, while half-open ranges `a..<b` exclude `b`, and both need `lowerBound <= upperBound`.
- The `==` operator tests value equality, while `===` tests whether two references point to the same class instance.
- The `??` operator unwraps an optional or returns a default value using short-circuit evaluation.
</Recap>
