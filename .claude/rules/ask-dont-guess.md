# Ask, don't guess

When something is unclear or is the user's decision, **ask the user before you continue**. Do not guess and do not pick a default without telling them.

- Ask before starting a step, not after building the wrong thing.
- Make questions easy to answer: short, simple English, with 2–4 clear options (use the AskUserQuestion tool). Put your recommended option first and say why in one line.
- Ask all the questions for a step together, so the user answers once.
- Facts are not questions for the user — find facts with a web search (`research.md`). Ask the user about choices: product, design, scope and priorities.
